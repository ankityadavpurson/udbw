# Universal DB Workbench

A cross-platform desktop workbench (Electron + React) for MySQL, PostgreSQL, Supabase, MongoDB and Firebase Firestore.

## Quick start

```bash
yarn install
yarn start      # builds the UI, then opens the app
yarn dev        # Vite dev server with hot reload
```

Requires Node.js 20 or newer and [Yarn 1](https://classic.yarnpkg.com/).
